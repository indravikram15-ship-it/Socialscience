# Social Science – Digital Interactive Book

A browser-based interactive digital textbook for Social Science (Grades 6–8).

## Features

- 📚 **4 Chapters** – Geography, History, Civics, Economics
- 🗺️ **Table of Contents** – slide-out drawer for quick navigation
- 🖱️ **Drag-and-Drop Activities** – match climate zones, civilisations, and more
- 📝 **Mini Quizzes** – multiple-choice questions with instant feedback at the end of each chapter
- ⌨️ **Keyboard Navigation** – arrow keys to flip pages
- 📱 **Responsive** – works on desktop and mobile

## Running Locally

Just open `index.html` in any modern browser – no build step or server required.

```
open index.html   # macOS
start index.html  # Windows
xdg-open index.html  # Linux
```

## Structure

```
index.html   – Book shell (cover, pages, quiz modal)
style.css    – Styling & animations
script.js    – Book content, navigation, drag-and-drop, quizzes
```
